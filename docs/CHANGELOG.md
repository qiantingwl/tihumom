# 更新记录

## v0.2.1 · 2026-09-28

首个公开仓库版本，包含 2026-09-26 已上线的作品渲染修复。

- 交互预览在尺寸就绪后显示动画，消除静态截图与动画叠层及切换闪动；慢加载保留等待提示。
- 分享链接、二维码定位到指定作品；首页、作品库与对比页面保留统一展示逻辑。
- 作品按内容去重展示，保留原始 ID 与历史记录；对拍使用真实预览端点。
- 完整 Docker 构建包含 PNG 品牌素材及后端依赖的共享 catalog 模块。
- 分享、二维码、API 文档的公开域名可通过构建变量 `VITE_PUBLIC_ORIGIN` 配置，默认 `https://www.tihu.mom`。
- 补充首次安装、宝塔反向代理、HTTPS、数据迁移、升级与回滚教程。
- 新增干净源码构建、自动测试和无上游调用的部署冒烟检查。

此版本不附带生产数据；新部署的作品库为空。已有站点升级需保留原 `data/` 和 `.env`。
